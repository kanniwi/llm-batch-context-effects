# Качество классификации по уровню токсичности соседей и по группам целевых

Источник: основной эксперимент `h1` (300 целевых, ответы при запрошенной T=0), таблицы `reports/tables/<модель>_h1_classification_by_level_stratum.csv`.

Определения: accuracy — доля верных ответов; F1 — по классу TOXIC; FPR — доля нетоксичных целевых, названных токсичными; FNR — доля токсичных целевых, названных нетоксичными. «Без соседей» — одиночный запрос. Уровень = доля токсичных среди 8 соседей.

Группы: **clear (все явные)** — 75 токсичных + 75 нетоксичных, для них считаются все показатели. **clear_toxic** (только токсичные: определены accuracy = 1 − FNR и FNR), **clear_nontoxic** (только нетоксичные: accuracy = 1 − FPR и FPR). **ambiguous** (доля разметчиков 0,4–0,6): эталон условный (доля ≥ 0,5), по сути близкий к подбрасыванию монеты, показатели справочные.
