# Методы

## Данные
Jigsaw Unintended Bias in Toxicity Classification (английские комментарии). Фильтры: ≥ 10 разметчиков, доля не-ASCII ≤ 5 %,
доля уникальных слов ≥ 0.5, ≤ 2.5 токена на слово. Целевые (300): 75 явно токсичных (доля разметчиков ≥ 0.8), 75 явно
нетоксичных (= 0), 150 спорных (0.4–0.6). Пул соседей (800): 400 токсичных + 400 нетоксичных. Seed выборки 42.

## Запрос
Один запрос = список из n комментариев `[i] текст`; модель отвечает построчно `<i>: TOXIC | NOT_TOXIC`. Одиночный запрос — n = 1
(контроль без соседей). Батч — 1 целевой + 8 соседей. Неразобранные ответы и ответы, обрезанные по длине, не кэшируются и
учитываются в доле «не разобрано» (по уровню и по позиции).

## Эксперименты
* **h1** — 300 целевых × 5 уровней (0/2/4/6/8 токсичных из 8 соседей) × 3 повтора с разными наборами соседей = 4 500 батчей
  (+ 1 100 одиночных: 300 целевых и 800 соседей). Наборы вложены (при росте уровня добавляются токсичные), длина соседей
  в пределах ±15 % по токенам (при нехватке ±20 %, ±30 %), сосед не из той же ветки обсуждения (`article_id`). Позиция целевого (1, 5, 9)
  определяется повтором, поэтому позиция в h1 смешана с набором соседей.
* **h1c** — 300 целевых (все) × уровни {0 %, 100 %} × все 9 позиций = 5 400 батчей (первые 100 целевых совпадают с первым этапом); соседи и их порядок фиксированы по позициям — позиция скрещена с составом.
* **repeats** — 300 батчей основного набора (по 60 на уровень) и 300 одиночных, независимые повторы `sample` = 0, 1, 2 при рабочей температуре.
* **uncertainty** — 300 одиночных × 10 ответов при T = 1: u = доля TOXIC; 0.5 — максимальная неуверенность.
* **h3** — *черновик*: определения условий и «нейтральных» соседей согласуются с научным руководителем.

## Метрики
* Эффект состава = доля TOXIC при 100 % токсичных соседей − при 0 %, **внутри каждого целевого** (усреднение по повторам и позициям), в п.п.; ИК 95 % — бутстреп по целевым (2 000 выборок).
  Вывод: эффект значим, если ИК не содержит 0.
* GEE (логит и линейная, обменная корреляция, кластер — целевой): наклон по доле токсичных соседей; точный тест Макнемара на мажоритарных ответах.
* Позиция: наклон по позиции (GEE) при 0 % и 100 %; тест взаимодействия состав × позиция (Wald).
* Шум: доля запросов, где ответ различается между независимыми повторами; κ Коэна.
* Температура: доля целевых, у которых мажоритарный ответ при T = 0 и T = 1 различается (одиночные запросы).
* Качество (явные целевые): accuracy, precision, recall, F1, FPR, FNR по уровню; для спорных — доля TOXIC модели vs доля разметчиков (эталонной метки нет).
* H2: разность эффектов спорных и явных (бутстреп) и эффект по корзинам неуверенности u (exploratory).
* Exploratory (помечены в имени файла): нормализация (сколько TOXIC в батче vs истинная доля), серия одинаковых меток перед целевым, точность разметки соседей.

## Правила интерпретации
1. Значимость — по ИК относительно 0, а не по попаданию оценки в собственный интервал.
2. Потолок: если модель уже в большинстве случаев говорит TOXIC (особенно явно токсичные целевые), рост невозможен — эффект по подгруппам читать с учётом базовой доли.
3. Модель завышает токсичность в целом (доля TOXIC выше доли разметчиков): это общий сдвиг, он не отменяет сравнение «внутри целевого».
4. Результаты разных моделей сравниваются качественно (знак и порядок величины), а не усредняются.
5. Заранее не заданные анализы помечаются exploratory и не используются как подтверждающие.
